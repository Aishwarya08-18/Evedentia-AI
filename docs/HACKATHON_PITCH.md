# EVEDENTIA AI — 90-second hackathon pitch

Businesses often make decisions using reports from Sales, Finance, Inventory and Operations. Those systems can disagree about the same order. Teams spend hours finding which value is reliable, and an incorrect correction can create financial or fulfilment risk.

EVEDENTIA AI is an explainable, multi-source data investigation and reconciliation prototype. A user signs in, uploads department exports, selects a shared business key, and runs an investigation. The workflow validates schemas, links records, detects field-level conflicts, preserves the observed value and source as evidence, suggests possible causes, and proposes a resolution using an explicitly configured source-of-truth rule or an unambiguous majority. Ties remain unresolved for a human reviewer.

The key difference is that EVEDENTIA AI does not silently overwrite data. It shows what disagrees, where each value came from, why a proposal was made, and where a human decision is still required. This supports auditable, safer data operations.

Today this is a local proof-of-concept using deterministic, explainable Python agents. The next production step is integration with ERP/CRM systems, event-level lineage, role-based approvals, immutable audit history and independently evaluated AI reasoning.
